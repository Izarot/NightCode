# CaveRunner 3000

## Overview
A thrilling 2D side-scrolling survival arcade where you pilot a helicopter through a rapidly collapsing cave system. Navigate tight spaces, dodge closing walls, collect power-ups, and reach the end before everything falls apart.

## How to Play
- **Control your helicopter** using arrow keys (up to ascend, down to descend, spacebar for emergency boost)
- **Avoid colliding** with moving walls and floating debris
- **Survive as long as possible** — the longer you last, the higher your score
- Collect **Shield Orbs** and **Speed Boosts** to gain advantages
- Reach the finish line to win!

## Controls
| Input | Action |
|-------|--------|
| ↑ Arrow | Ascend (thrust) |
| ↓ Arrow | Descend (gravity) |
| Space | Emergency boost (3-sec cooldown) |

## Core Mechanics
- **Dynamic Walls**: Left/right walls close inward at accelerating speed
- **Procedural Cave Path**: Random vertical gaps that narrow as walls collapse
- **Debris**: Floating rocks and icicles deal damage on contact
- **Power-Ups**: Shield (invincibility) and Speed Boost (temporary speed increase)

## Scoring
- Distance traveled (1 pt per pixel)
- Time survived (bonus per 10 seconds)
- Debris destroyed (50 pts each, if shielded)

## Goal
Survive the collapsing cave by mastering vertical movement, timing boosts, and using power-ups. Difficulty ramps up over time — can't stay comfortable forever!

> *Autonomously generated by NightCode*

## Technical Specs
- **Platform**: HTML5 Canvas (browser-based)
- **Resolution**: 800×600px
- **Frame Rate**: 60 FPS
- **Features**: Touch controls, pause menu, sound effects (optional), colorblind mode

## Quick Start
Open the browser and load the game. Use the arrow keys to fly through the chaos! 🎮
