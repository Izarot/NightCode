# 🌪️ Zephyr Strike

> **The wind doesn't just blow... it aims.**

A top-down physics shooter where the weather is your deadliest opponent. Master the gale, curve your shots, and survive the storm.

---

## 🎮 How to Play

| Input | Action |
| :--- | :--- |
| **WASD / Arrow Keys** | Move (Momentum-based physics!) |
| **Mouse** | Aim |
| **Left Click** | Fire |
| **1 / 2 / 3** | Switch Ammo Types |

### 💨 The Wind Mechanic
A global **Wind Vector** shifts every 5–10 seconds.
*   **Watch the Compass (Top Center):** Green = Calm, Yellow = Breezy, Red = **Gale Force**.
*   **Watch your Cape:** Your scarf flutters in real-time wind direction.
*   **Watch your Crosshair:** It auto-offsets to show predicted drift.

### 🔫 Ammo Types
*   **Standard (1):** Curves with the wind. *Curve shots around cover.*
*   **Stable (2):** Ignores wind. *Slow fire, true aim.*
*   **Scatter (3):** Wide spread, extreme drift. *Chaos incarnate.*

## ✨ Features
*   **Additive Glow Rendering:** Neon trails via `globalCompositeOperation='lighter'`.
*   **Parallax Depth:** 3-layer background scrolling.
*   **Dynamic Vignette:** Screen darkens as the storm intensifies.
*   **Zero Dependencies:** Pure HTML5 Canvas / Vanilla JS.
