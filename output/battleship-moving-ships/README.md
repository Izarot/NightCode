# Battleship: Naval Warfare

Set sail, command your fleet, and sink the enemy before they sink you! Navigate a living ocean, outmaneuver rival ships, and unleash everything from long-range cannon fire to torpedoes.

## How to Play

- **Left-click** a friendly ship to select it.
- **Left-click the ocean** to set a course.
- **Right-drag** to pan the camera; **scroll** to zoom.
- Use **WASD** to move the camera and **Tab** to cycle ships.
- Hold **right-click** to open the radial command menu.
- Press **1–5** to select weapons, then click a target to fire.
- Hold **Shift** for precise waypoint placement.
- Press **Space** for an emergency stop.
- Use **Ctrl+1–4** to deploy tactical formations.

Keep an eye on your minimap, health, reload timers, and detection circles. Momentum matters, so turn early, stay clear of islands and friendly fire, and remember: the fastest ship is not always the safest.

## Features

- Four playable ship classes with distinct speed, armor, and weapons
- Real-time naval physics, projectile ballistics, and tactical AI
- Dynamic weather, waves, lighting, explosions, and engine wakes
- Radar, sonar, stealth, critical damage, and formation commands
- A responsive 15×15 battlefield built for desktop and touch devices
