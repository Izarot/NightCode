# 🏰 Evolve & Conquer

*A dungeon crawler where monsters don't just die — they **evolve**.*

---

## ⚔️ How to Play

**Move** — `WASD` / `Arrow Keys`  
**Jump** — `Space` (hold for height!)  
**Crouch/Wall-Jump** — `Shift`  
**Attack** — Click / `Enter` (melee, ranged, or magic)  
**Scan** — Mouse drag to aim/look around  

### The Loop
1. **Explore** procedurally generated dungeons
2. **Fight** monsters in turn-based or real-time combat
3. **Collect** evolution components from fallen foes
4. **Watch** monsters transform — Shadow Stalker → Void Reaper → **Eclipse Lord**
5. **Unlock** new abilities, tougher variants, and deeper floors

> 💡 *Defeat 3 Shadow Stalkers → unlock Shadow Lurker. Kill 25 Lurkers → face the Void Reaper. Survive the Eclipse Lord... if you can.*

## ✨ Features

- 🎲 **Infinite dungeons** — new layout every run
- 🧬 **Living bestiary** — 4-stage evolution chains per monster
- 🎨 **Pixel art + dynamic lighting** — color shifts, particle bursts, scale changes on evolution
- 📊 **Evolution Tracker HUD** — progress rings, requirement checklists, material counts
- 💾 **Auto-save** — pick up where you left off (LocalStorage)
