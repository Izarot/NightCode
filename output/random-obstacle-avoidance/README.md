## 🎮 How to Play

| Input | Action |
|---|---|
| `WASD` / `Arrow Keys` | Move your vessel (8 directions) |
| `Right Mouse Button` | Toggle mouse-follow aim mode |
| `SPACE` | Start / Retry |
| `ESC` | Pause |

**Objective:** Survive. That's it. No health bars, no second chances in default mode — one touch of a reactor fragment and your run is over.

**Tips:**
- 🌀 **Trust the near-misses** — bonuses are awarded for *almost* dying (+0.25s per close call).
- ⚠️ **Watch the yellow Trackers** — they're the only ones that home in on you.
- 💥 **Splitters telegraph** — red pentagons explode into three shards after 2 seconds. Give them space!
- 🏆 **Milestones every 30s** — the screen flashes white to mark your progress.
- 🥇 **Top 10 scores persist** via local storage. Claim the leaderboard.
