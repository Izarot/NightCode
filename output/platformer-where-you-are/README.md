# 🟢 Squishy Slime大平台 🟢

A 2D HTML5 Canvas platformer where you control a sentient, gelatinous slime navigating procedurally generated obstacle-filled worlds! 

## 🎮 How to Play
*   **Move:** Arrow keys or WASD
*   **Jump:** Spacebar (Hold for full height, tap for short hops)
*   **Dash:** Double-tap Spacebar for a quick horizontal burst!
*   **Gel Mechanic:** Absorb gel blobs to grow (harder to navigate) or expel them to shrink (better for tight spaces).
*   **Enemies:** Avoid spikes and flying saws, or absorb small enemies to turn them into gel!

## 🌟 Features
*   **Squishy Physics:** Springy bounces, variable jump heights, and dynamic squash & stretch animations.
*   **Neon Aesthetic:** Vibrant colors, glowing collectibles, and parallax scrolling backgrounds.
*   **Particle Heaven:** Satisfying dust, landing splats, and dash trails.
*   **Responsive HUD:** Glassmorphism UI with health, score, and size indicators.
