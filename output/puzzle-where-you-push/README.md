# Block Protocol: Pressure Shift

A futuristic Sokoban‑style puzzle where you push blocks onto pressure plates to unlock the exit.

## How to Play
- Move with **Arrow Keys** or **WASD** (one grid step per press).  
- Push a block if the space behind it is free.  
- Get every pressure plate covered by the correct block to open the portal and finish the level.  
- Use **R** to reset the level if you get stuck.  
- On mobile, swipe or use the on‑screen D‑pad.
