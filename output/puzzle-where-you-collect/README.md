# MOSAIC — The Fragment Keeper

## Complete Technical Game Specification v1.0

A single-player, top-down 2D puzzle game for HTML5 Canvas. You explore a dark, atmospheric level as a lantern-bearing restorer, locate glowing **fragments** of a shattered painting, and place them into a **Restoration Frame** to complete the image. Each correctly placed piece reveals more of the masterpiece; finishing the frame triggers a cinematic reveal and unlocks the next, larger level.

**Genre:** Exploration / Jigsaw / Environmental Puzzle  
**Session length:** 8–15 min per level, 3 levels total  
**Tone:** Calm, mysterious, rewarding. No death, no fail state, no time pressure.  
**Platform:** Desktop browser (keyboard + mouse). One self-contained `index.html`, zero external dependencies.

## How to Play

1. **Explore** the level with 8‑direction movement and a dash.  
2. **Locate** fragments — faint pulsing glows visible through the darkness.  
3. **Solve** environmental puzzles (plates, crates, mirrors, runes) to reach gated fragments.  
4. **Collect** fragments on contact; they fly into the HUD tray.  
5. **Restore** — press `TAB` to open the Restoration Frame, pick a fragment, and drop it onto the empty cells of the mosaic grid.  
6. **Reveal** — each correct placement lights up that region of the painting.  
7. **Complete** — when all cells are filled, a cinematic plays, a caption appears, and the next level loads.

**Controls**

| Key | Action |
|---|---|
| `WASD` / Arrow keys | Move (max speed 230 px/s, acceleration 1500 px/s²) |
| `Space` or `Shift` | Dash forward at 620 px/s for 0.14 s (dash cooldown 1.1 s) |
| `TAB` | Open Restoration Frame |

**Player entity**: circle, radius `r = 11 px`, centre `(x, y)`, velocity `(vx, vy)`. Friction 2000 px/s², max speed 230 px/s, dash locked to input direction.

## World, Camera & Rendering

- **Tile size:** 32 px. Levels:  
  - Level 1 – 44×26 tiles (1408×832 px) – *First Light*  
  - Level 2 – 56×32 tiles (1792×1024 px) – *The Quiet City*  
  - Level 3 – 64×40 tiles (2048×1280 px) – *Bloom*  
- **Camera:** internal 1280×720 render, target = player, smoothing `t = 1‑exp(-8·dt)`. Screen shake: 2 px on fragment collect, 3 px on gate opening, 6 px on painting completion.  
- **Render pipeline (per frame)**: clear → draw tiles → draw puzzle objects → draw fragments → draw particles → lighting pass → glow pass → vignette + film grain → HUD/UI.  
- **Pixel ratio:** `canvas.width = cssWidth × dpr`, `canvas.height = cssHeight × dpr`; use `ctx.setTransform(dpr,0,0,dpr,0,0)` for scaling.

## Fragment System

Each fragment has:
- `id` (int)  
- `cell` = (col, row) in the mosaic grid  
- `worldX, worldY` spawn position  
- `state`: HIDDEN → AVAILABLE → COLLECTED → PLACED  
- `bobPhase` random idle offset  
- `glowColor` sampled from the fragment’s image region.

**Counts** (level‑specific):  
- Level 1: 9 fragments (3×3)  
- Level 2: 16 fragments (4×4)  
- Level 3: 25 fragments (4×5 grid)
