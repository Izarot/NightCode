

# 🎮 Angle-Breakout

**Smash bricks. Spin the paddle. Defy the angle!**

Welcome to *Angle-Breakout*, a high-octane HTML5 Canvas arcade game where the paddle isn't just a barrier—it's a weapon. Tilt it, aim it, and launch your way through increasingly chaotic levels at a smooth 60 FPS.

## 🕹️ How to Play

| Input | Action |
| :--- | :--- |
| **Mouse / Touch Drag** | Move the paddle left and right |
| **Mouse Wheel / Arrow Keys** | **Rotate** the paddle (‑45° → +45°) |
| **Click / Tap** | Launch the ball |
| **Space / Enter** | Pause / Resume |

### 💡 Pro Tips
*   **Angle Matters:** The direction you tilt the paddle determines where the ball flies!
*   **Watch the Spin:** Hitting the ball with a moving paddle adds curve shots.
*   **Collect Power-Ups:** Grab them to expand your paddle, fire lasers, or summon extra balls.
*   **Don't Drop It:** If the ball hits the bottom, you lose a life.
