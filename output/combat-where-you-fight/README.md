# 🌪️ WIND BLADE

*A top-down arena combat game where you wield the power of the wind itself.*

You are a wind mage, standing alone against waves of elemental creatures in floating sky arenas. Your enemies? Fire and stone. Your weapon? *Everything else.*

## 🎮 How to Play

### Controls
| Input | Action |
|-------|--------|
| **WASD / Arrows** | Move with momentum |
| **Left Click** | Pulse Gust — pushes enemies away |
| **Shift + Click** | Pull Vortex — drags enemies in |
| **Hold Mouse** | Directional Stream — continuous wind beam |
| **E** | Cyclone Burst — spawns a tornado |
| **Space** | Dash through danger (or Wind Shield) |
| **ESC** | Pause |

### Enemy Types
- 🔥 **Ember Sprites** — Fast chasers, 1 HP
- 🪨 **Stone Golems** — Slow tanks that shoot fireballs
- 💥 **Flame Wisps** — Float erratically, explode on contact
- ⚡ **Storm Drakes** — Later waves, briefly immune to wind

### Core Loop
Survive waves of enemies. Chain kills for combo multipliers. Don't get hit for bonus points.
