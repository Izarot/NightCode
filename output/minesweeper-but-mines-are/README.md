# 🚨 Moving Minesweeper

**The classic puzzle game where nothing stays safe for long.**

---

## 🎮 How to Play

| Action | Control |
|--------|---------|
| Reveal a cell | Left Click |
| Place/Remove a flag | Right Click |
| Start over | Click "NEW GAME" |

### The Twist
Unlike traditional Minesweeper, **mines relocate every few seconds** to adjacent cells. A safe square today might be a death trap tomorrow. Stay alert, think fast, and never assume you're completely safe!

### Objective
Reveal all non-mine cells to win. Click a mine and it's game over.

### Difficulty Levels
- **Easy** — 9×9 grid, 10 mines, 4s between moves
- **Medium** — 16×16 grid, 40 mines, 3s between moves
- **Hard** — 16×30 grid, 99 mines, 2s between moves

- Dynamic mine movement that keeps you on your toes
- Smooth canvas animations and visual feedback
