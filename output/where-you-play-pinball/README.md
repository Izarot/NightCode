#  🧙‍♂️ Pinball Wizard

*An infinite vertical pinball adventure where physics meets wizardry!*

## 🎮 How to Play

**Objective:** Launch your cyan wizard ball upward through an endless pinball table, smashing gold flags and power capsules while dodging crimson spike blocks. Reach new heights to level up!

### Controls
| Key / Action | Effect |
|--------------|--------|
| `←` `→` / `A` `D` | Steer left/right |
| `↑` `↓` / `W` `S` | Nudge up/down |
| `Space` / `Click` | **LAUNCH BOOST** — temporary speed surge |

### Scoring Targets
- 🏁 **Gold Flags** — 100–500 pts + speed boost & invincibility
- 💜 **Power Capsules** — 300 pts + pick a perk (Shield, Super Jump, Invincibility)
- 🚫 **Spike Blocks** — −20 pts & speed loss (avoid!)
- 🎯 **Goal Zones** — 150 pts + level progression
