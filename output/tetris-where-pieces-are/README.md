# 🎲 Cubetris

> A classic Tetris twist — every block is a tiny cube that **spins in place** while you play!

## 🚀 How to Play

Drop, rotate, and clear lines just like the original — but watch your blocks shimmer and spin as they fall.

| Action | Keyboard | Touch |

| Soft Drop | ↓ | Swipe Down |
| Hard Drop | Space | Swipe Up |
| Rotate | ↑ | Tap |
| Hold Piece | C / Z | Long Press |
| Pause | P | Pause Button |
