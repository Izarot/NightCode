# ChromaShift

## How to Play
- **Select** an object by clicking/tapping it – a white outline and color aura appear.  
- **Swap** by clicking/tapping a second object (or drag‑to‑swap). Colors blend over 0.15 s with a particle burst, and the objects’ physics properties update instantly.  
- **Goal:** guide any object into the goal zone to complete the level.  
- **Undo** the last swap with **Z** (up to 5 undos).  
- **Pause** the game with **Esc**.

## Controls
- **Mouse / Touch:** select → select target → swap (or drag‑to‑swap).  
- **Keyboard:** `Enter` to confirm swap, `Z` to undo, `Esc` to pause, arrow keys to move focus.
