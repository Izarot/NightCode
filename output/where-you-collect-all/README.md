# Velocity Vault

## How to Play
- Run, jump, and dash your way through each level.  
- Collect **all** coins before the timer runs out.  
- Watch out for spikes, crushers, lasers, and other hazards—they’ll cost you health.  
- You have **3 hearts** of health; lose them all and the game ends.  
- Finish fast for medals, high scores, and bragging rights.

## Objective
Gather every coin in the current level before the **Time Limit** expires. Reach **100 % coin collection** for a perfect run and unlock the next level.
