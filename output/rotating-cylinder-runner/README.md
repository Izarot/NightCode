# 🎮 Cylinder Rush

## The Ultimate Rolling Adventure!

Dodge obstacles, collect coins, and survive the spin in this mind-bending endless runner where you run *around* a cylinder!

---

## 🎯 How to Play

| Control | Action |
|---------|--------|
| `←` / `→` or `A` / `D` | Switch lanes |
| `SPACE` / `W` / `↑` | Jump! |
| `P` or `ESC` | Pause game |

**Goal:** Survive as long as possible while racking up points!

- 🪙 **Collect coins** for bonus points
- 🛡️ **Grab power-ups** for shields, magnets, and more
- ⚡ **Near misses** give you extra style points
- 🔥 **Difficulty increases** the longer you survive
