# 🗺️ Rotating Labyrinth

A dizzying puzzle-action game where the maze spins continuously.

## How to Play
**Goal:** Complete objectives before time runs out.
- **Collect Keys** - Gather all keys in the maze
- **Reach Exit** - Touch the moving exit
- **Avoid Laser** - Survive the rotating hazard

**Controls:** WASD / Arrow Keys

**Features:**
- Procedurally generated maze (recursive backtracker)
- Continuous rotation with increasing speed
- Web Audio API sound effects
- LocalStorage high score persistence
- Speedrun timer
- Responsive canvas
- Emoji favicon

Open index.html in any modern browser.
