# Magnetic Mayhem

**Genre:** Physics-Based Puzzle Platformer  
**Platform:** HTML5 Browser

## How to Play
- Move your magnet with **WASD** or **Arrow Keys** (or drag on mobile)
- Attract scattered metal objects automatically as you get close

- Clear all objects before the 60-second timer expires!
