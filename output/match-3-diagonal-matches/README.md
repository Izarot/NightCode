# 🔷 Diagonal Match-3

Match tiles on the diagonal and watch the board pop!

## How to Play

- Swap a tile with an orthogonal neighbor (up, down, left, or right) using mouse, touch, or keyboard.
- Match 3 or more tiles in a row — diagonally (`\` or `/`) for bonus points, or orthogonally.
- Invalid swaps bounce back and don't cost a move.
- Reach the target score before you run out of moves to win the level!
- Match 4 for a Line Tile, 5 for a Bomb, and trigger cascades for huge multipliers.

Good luck — think diagonally!
