## How to Play

### Controls
| Action | Key |
|--------|-----|
| Move / Walk | `WASD` or arrow keys |
| Fire projectile | Left mouse button **or** `Space` |
| Dash (instant speed boost) | `Shift` |
| Pause / Resume | `P` or `Esc` |
| Restart after game over | `R` |

- Mouse position does **not** affect aiming. The crosshair (`C`) is anchored near the centre and nudged by enemy velocities.
- All controls are keyboard accessible except firing (which also uses `Space`).

### Gameplay Loop
1. Survive waves of neon enemies inside a dark arena.
2. Enemies move according to AI; their velocity pushes the Aim Drone around.
3. Move, herd, and dash to reposition enemies → steer the drone.
4. Press fire → projectiles travel toward the drone’s current position.
5. Hits reduce health, generate score, trigger effects.
6. Manage health, weapon heat, dash cooldown while clearing waves.
7. Game ends when your health reaches 0; final score & wave shown, then press **`R`** to restart.

## Aim Drone Physics (Crosshair)

- Position `C`, velocity `Vc`.
- **Force from each enemy**:
  - `dist = distance(C, enemy.position)`
  - `falloff = clamp(1 - dist/600, 0.15, 1.0)`
  - `speedFactor = 0.5 + enemy.speed/200`
  - `force = enemy.velocity * 0.9 * falloff * speedFactor`
- **Drone acceleration**: `A = sum(forces) - (C - arenaCenter)*0.6 - Vc*2.2`
- **Maximum speed**: 420 px/s.
- Spring anchor to arena center (weak spring coefficient 0.6).
- Never teleported except during wave reset/restart.
- Visual: bright yellow/white concentric rings, rotating tick marks, velocity tail, pulse on high influence.
