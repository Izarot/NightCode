## 🎮 How to Play

**Your Mission:** Build towers that reach the target height using limited blocks!

### Quick Start
1. **Select** a block from the palette on the left
2. **Drag** it onto the build zone
3. **Drop** to place — watch for the green ghost (valid) or red ghost (invalid)
4. **Stack** blocks until your tower hits the target height
5. **Earn stars** based on how efficiently you build!

### Block Types
| Block | Shape | Special |
|-------|-------|---------|
| 🟧 Square | 1×1 | Basic filler |
| ➖ Domino | 2×1 | Horizontal stabilizer |
| ⏬ T-Block | T-shape | Complex connector |
| ⏰ L-Block | L-shape | Corner piece |
| ➕ Long | 1×3 | Vertical support |

### Tips & Tricks
- 🔴 **Red ghost?** Block is floating or overlapping — try again!
- 🟢 **Green ghost?** Perfect placement — click to lock it in!
- ⭐ **Use fewer blocks** for more stars — efficiency wins!
- 🔄 **R key** restarts the level if you get stuck

### Controls
| Key | Action |
|-----|--------|
| Click Palette | Select block |
| Click Grid | Place block |
| Right Click / Esc | Cancel selection |
| R | Restart level |
