# Water Sort Puzzle

**Description**  
A quick‑thinking puzzle where you sort mixed colored liquids into clean tubes. Each tube can hold up to 4 units, and only matching colors (or empty tubes) can be poured.

**How to Play**
- **Select source** – tap a tube containing the top‑most color.  
- **Choose destination** – tap another tube (must be empty or hold the same color).  
- **Pour** – the liquid slides smoothly into the destination.  
- **Repeat** until every non‑empty tube has a single, uniform color.  
- Use **Hint** (lightbulb) to highlight a valid move, and **Undo** (arrow) to step back any mistake.

**Controls**
- Tap/click to interact.  
- Hint button (💡) – shows a valid pour pair.  
- Undo button (⟲) – reverts the last move.
