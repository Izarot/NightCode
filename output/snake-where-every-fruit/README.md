# Rule Snake 🐍✨  

**Play a neon‑lit twist on the classic snake game where every fruit you eat rewrites the rules!**  

---  

## How to Play  

1. **Start** – Hit **Start** on the main menu or tap the screen.  
2. **Control** – Use the arrow keys / WASD (or on‑screen pads on mobile) to steer the 5‑segment snake.  
3. **Eat Fruit** – Grab the glowing pink fruit to score a point.  
4. **Rule Change** – Each fruit instantly swaps the active rule (e.g., walls become passable, the map wraps around, directions invert, etc.).  
5. **Adapt** – The new rule takes effect immediately; stay alive by adjusting your path.  
6. **Game Over** – Crash into a wall (or the screen edge when not allowed), run into yourself, or trigger a rule‑specific hazard. The game shows “RULE BROKEN”, plays a death sound, and lets you restart.

- **Keyboard** – Arrow keys or **WASD** for direction.  
- **Touch** – Tap the on‑screen directional pads (64 × 64 px circles) on mobile.
