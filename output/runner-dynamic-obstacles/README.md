# Runner with Dynamic Obstacles

A fast-paced 2D endless runner built with HTML5 Canvas. Dodge spikes, roll under barriers, and leap across gaps as the world speeds up around you.

## How to Play
- **Space / Up Arrow**: Jump  
- **Down Arrow**: Slide  
- **Left / Right Arrow**: Change lanes  
- **P**: Pause  
- **R**: Restart (after game over)

Survive as long as you can, collect power-ups, and rack up combos for a high score!

## Features
- Procedurally generated obstacles  
- Lane switching, jumping, and sliding  
- Combo multiplier scoring  
- Power-ups: Speed Boost, Shield, Extra Life  
- Local high-score storage  
- Desktop and mobile browser support
