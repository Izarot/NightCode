# Light-Cycle Phase

## 🎮 A Neon-Lit Racing Challenge

**Light-Cycle Phase** is a 2-D HTML5 Canvas racing game where you pilot a glowing light-cycle through procedurally-generated tracks. Each lap earns you one **Phase** charge — activate it to become semi-transparent, leave a ghost-trail, and slip past static walls (but still hit real obstacles!). Complete the required number of laps to claim victory.

---

## 🕹️ How to Play

### Core Loop
1. Select your bike and choose a race mode (Arcade, Marathon, Survival, or Multiplayer).
2. Thrust forward/backward and rotate the bike with arrow keys or WASD.
3. Press **Space** to **Phase** (once per completed lap).
4. Navigate the track, avoid collisions, and reach the finish line.

### Controls
| Input | Action |
|-------|--------|
| Arrow Keys / WASD | Move forward / backward |
| A / D or Left/Right | Rotate bike (continuous) |
| **Space** | Activate Phase (once per lap) |
| **P** | Pause menu |
| **R** | Restart race |
| **Esc** | Return to main menu |

### Race Modes
- **Arcade** – 3-lap sprint, phase once per lap.
- **Marathon** – 10-lap endurance run.
- **Survival** – Continuous race with increasing hazard density.
- **Multiplayer** – Up to 4 players (split-screen or online).

### Winning
Cross the finish line after completing the target number of laps (default 3) to win. Points are awarded per lap (+50 bonus for non-phase runs) minus penalties for collisions.
