# AstroManeuver: Fractured Cosmos

## 🚀 What Is This Game?

A thrilling 2D space shooter where you pilot a retro-futuristic ship through a chaotic asteroid field. Each asteroid has unique, unpredictable behaviors—some hunt you, some explode, others bend reality itself. Survive long enough to claim victory!

## 🎮 How to Play

**Controls**
- 🕹️ Arrow Keys — Rotate left/right, thrust forward
- ⬆️ Spacebar — Fire projectiles (cooldown: 10 frames)
- 🖱️ Mouse — Optional precise aiming

**Gameplay**
Navigate your spaceship through a constantly shifting asteroid battlefield. Destroy asteroids to earn points and trigger special behaviors. Watch out for homing threats, exploding splitters, and gravity wells that pull everything together!

**Win Conditions**
- Survive for **3 minutes** without hitting an asteroid
- OR destroy **100+ asteroids** (large ones give bonus points!)
