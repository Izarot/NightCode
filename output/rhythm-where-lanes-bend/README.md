# Curve Beat 🎮

> **A rhythm game where curved lanes pulse toward center on every beat.** Tap notes as they travel along bending paths — precision is everything.

## How to Play

1. **Select a song** and difficulty (4–8 lanes)
2. **Watch notes** travel along curved lanes toward the pulsing center target
3. **Tap notes** when they reach the target zone
4. **Chain hits** for combos and multipliers
5. **Hold notes** by dragging along the lane path
6. **Earn grades** (C → B → A → S → SS) based on accuracy

### Timing Windows
| Grade | Window | Points |
|-------|--------|--------|
| Perfect | ±50ms | 100 |
| Great | ±100ms | 70 |
| Good | ±150ms | 40 |
| Miss | >150ms | 0 |

## Controls
- **Desktop**: Mouse click / Keyboard keys `1`–`8`
- **Mobile**: Touch and drag along lanes
