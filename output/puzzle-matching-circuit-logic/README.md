# ⚡ CircuitLogic: The Puzzle of Truth

> *Wire it. Test it. Light it up.*

Welcome to **CircuitLogic** — a brain-tickling, solder-scorching puzzle game where Boolean logic meets block-dropping chaos! Build real circuits. Solve real logic. Make a tiny lightbulb feel like the greatest achievement of your life.

---

## 🎮 How to Play

1. **Study the Goal** — Look at the top bar to see what condition needs to light the bulb.
2. **Grab Components** — Drag logic gates, wires, and splitters from the left inventory panel.
3. **Snap & Place** — Drop components onto the grid. They auto-snap to cells.
4. **Rotate** — Right-click, press `R`, or pinch-rotate on mobile to spin components 90°.
5. **Connect the Dots** — Make sure all ports line up: wires to wires, gates to wires, gates to the bulb!
6. **Hit "Test Circuit"** — Watch the electricity flow and see if the bulb lights up! 💡
7. **Iterate & Optimize** — Fewer unused components = more ⭐ stars!

## 🧩 Component Types

| Component | Symbol | What It Does |
|---|---|---|
| **Wire (Straight)** | `──` | Transmits signal forward |
| **Wire (Corner)** | `└` | Bends a signal 90° |
| **AND Gate** | `D` | Outputs ON only if **both** inputs are ON |
| **OR Gate** | `≥1` | Outputs ON if **either** input is ON |
| **NOT Gate** | `¬` | Flips the signal (ON → OFF, OFF → ON) |
| **XOR Gate** | `⊕` | Outputs ON if inputs are **different** |
| **NAND Gate** | `⊼` | Outputs OFF only if **both** inputs are ON |
