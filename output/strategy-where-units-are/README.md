# Leafline Colony

A 2D HTML5 Canvas real-time strategy game where you command an ant colony against escalating waves of enemy spiders. Harvest leaves, build defenses, and survive 10 waves to claim victory!

## How to Play

1. **Select** ants with left-click (drag for box select, Shift+click to add).
2. **Command** with right-click — green = move, yellow = harvest, red = attack.
3. **Harvest** leaves from sources (auto-return to nest), then spend them to build workers, soldiers, turrets, or the Royal Chamber.
4. **Survive** 10 waves of spiders. Build the Royal Chamber to win!
5. **Lose** if the Nest HP reaches zero.

## Game Specs at a Glance
- **Resolution:** 1280×720 canvas, responsive scaling
- **Grid:** 64×64 cells, A* pathfinding with diagonals
- **Units:** Up to 150 ants + 50 enemies + 200 particles at 60 FPS
- **Resources:** Leaves start at 50; deposit +10 per harvest
- **Waves:** Spawn every 45s from map edges
- **Win:** Wave 10 cleared + Royal Chamber built
- **Lose:** Nest HP (500) reaches 0
