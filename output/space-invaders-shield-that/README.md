## 🎮 How to Play

**The Core Mechanic**
A massive **Aegis Core** splits the screen down the middle. It blocks *vertical* alien fire perfectly. **It does not block angled flank shots.** Hug the center to survive the rain; strafe the flanks to clear the horde—but watch your six.

**Controls**
| Key | Action |
| :--- | :--- |
| `←` / `→` or `A` / `D` | Strafe Left / Right (Momentum-based physics!) |
| `Space` / `↑` / `W` | Fire (250ms cooldown) |
| `Esc` / `P` | Pause / Menu |

**Survival Tips**
1.  **Trust the Core:** Standard aliens fire straight down. Stand *behind* the cyan pillar. You are invincible there.
2.  **Fear the Elite:** Yellow-visored Elites fire **parabolic/angled shots** designed to curve around the Core's edges. The red screen-border pulse means **YOU ARE EXPOSED**.
3.  **Manage Integrity:** The Core takes 3 hits. Cracks appear → Orange sparks → **CRITICAL FLASHING** → Destruction. No Core = No Cover.
4.  **Momentum is Real:** You accelerate at `0.8 px/f²` and drift to a stop (`0.6 px/f²` friction). Don't overshoot the safe zone!

**Scoring**
*   Standard Alien: **100 pts**
*   Elite Alien: **300 pts**
*   Fleet Clear Bonus: **5,000 pts**
*   Core Survival Bonus (per wave): **1,000 pts × Remaining HP**
