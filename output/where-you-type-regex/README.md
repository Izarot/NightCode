# Regex Runner
A fun regex-based arcade game! Type patterns to destroy falling projectiles.

## How to Play
- Projectiles with random text fall from the top
- Type a regex pattern and submit to match and destroy them
- Match patterns to gain points and advance levels
- Let projectiles reach the bottom and lose a life
- Game over when lives hit zero
- Use regex syntax: `^` start, `$` end, `[]` character classes, `*` zero or more, `+` one or more, `?` optional
