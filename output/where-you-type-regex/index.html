How to Play:

  • Projectiles with text will fall from the top
  • Type a regex pattern that matches the text to destroy them
  • Use regex syntax: ^ (start), $ (end), [] (character class), * (0+), + (1+), ? (0 or 1)
  • Destroy projectiles to gain points
  • If a projectile reaches the bottom, you lose a life
  • Reach 100 points to advance to the next level

Tip: Start simple with patterns like ^a to match only strings starting with 'a', then progress to more complex patterns!
