# Coral Quest: The Deep Dive

Dive into a vibrant, 2D underwater adventure where you control **Finley**, a curious fish on a mission to restore the reef. 🌊🐠

---

## How to Play

| Control | Action |
|---------|--------|
| **← / →** or **A / D** | Swim left/right |
| **↑ / ↓** or **W / S** | Ascend/descend |
| **Space** | Glide (2 s of reduced gravity) |
| **Esc** | Pause / open menu |

- **Collect** bioluminescent orbs to unlock new levels.  
- **Use** sonar pulses to reveal hidden paths (limited charges).  
- **Avoid** predators and toxic algae; heal with glowing seaweed.  
- **Solve** puzzles by activating levers and guiding smaller fish.  
- **Defeat** the final boss, a mutated octopus, by dodging ink and hitting weak points.
