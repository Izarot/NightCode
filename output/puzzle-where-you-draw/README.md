# 🎮 Line Guide Puzzle

**Draw. Guide. Solve.**  
A minimalist physics-puzzle game where *you* draw the path — and a curious little cube follows it with style.

---

## 🕹️ How to Play

1. **Draw Lines**  
   Click/touch and drag to draw paths. Minimum 5px. No overlapping. Be precise.

2. **Guide the Cube**  
   Your drawn lines become rails. The cube glides smoothly — straight lines? 0.5s response. Curves? Bézier magic with 0.3s grace.

3. **Reach the Target**  
   Get the cube to the glowing goal. Avoid red walls. Beat the clock. Use ≤10 lines.

4. **Fail? No Problem.**  
   Restart with a hint: *"Try a shorter path."* You’ve got 3 hints per level.
