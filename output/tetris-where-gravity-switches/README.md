**Tetris, but gravity has a mind of its own.**

## 🎮 How to Play

**The Twist:** Gravity isn't just *down* anymore. Every 10–15 seconds, it **flips** to a random direction (Down, Up, Left, or Right). Your piece falls toward the new "floor." Locked blocks? They stay put. Good luck.

**Clear Lines:** Fill a **row** *or* a **column** to clear it. Yes, vertical Tetris is real now.

### Controls
| Key / Touch | Action |
| :--- | :--- |
| `←` `→` `↑` `↓` | Move / Soft Drop |
| `X` / `↑` | Rotate Clockwise |
| `Z` | Rotate Counter-Clockwise |
| `Space` | **Hard Drop** (instant lock) |
| `C` | Hold Piece (once per drop) |
| `P` / `Esc` | Pause |
| `Enter` | Start / Restart |
| *Swipe Down* | Hard Drop (Mobile) |
| *On-screen Buttons* | Move, Rotate, Hold, Drop (Mobile) |

### Pro Tips
*   **Ghost Piece** shows where you'll land—watch it closely when gravity flips!
*   **Lock Delay** gives you 500ms to wiggle a piece after it touches down. Resets on moves/rotates (max 15x).
*   **7-Bag Randomizer** means you'll see every piece before repeats. Plan ahead.
*   **Simultaneous Clears** (Row + Column) grant massive intersection bonuses.
