# SCRAPKIN

**A kinetic scrap-assembly rogue-lite set in a neon-lit industrial hellscape.**

## How to Play

1. **Scavenge** – Run through hazardous zones, bump into scrap piles to collect gears, pistons, springs, and cables (max 4 inventory slots).  
2. **Assemble** – Hold **E** to open the assembly pad. Drag components together to build kinetic constructs (e.g., Gear+Shaft = propeller, Spring+Lever = launcher).  
3. **Deploy** – Press **Space** to activate your construct, attaching it to your position. Use momentum and shockwaves to stun enemies and break obstacles.  
4. **Survive** – Dodge automated scrap-drills and roaming security drones. Defeat them to drop more components.

**Controls:**
- **WASD / Arrow Keys** – Move
- **Mouse** – Aim / Targeting
- **E** – Open Assembly Pad
- **Space** – Deploy Construct / Launch
