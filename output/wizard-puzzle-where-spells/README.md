# Arcane Alchemy  
*2D Puzzle‑Platformer with Spell‑Based Problem Solving*  

## How to Play  
- Move with **← →** or **A/D**, jump with **Space** (tap for short hop, hold for double‑jump).  
- Select spells with **1‑4** (or swipe on mobile) and cast with **Click/Tap** toward the cursor.  
- Use **Fireball** to break walls, **Ice Spike** to create platforms, **Wind Blast** to push objects, **Light Beam** to reveal hidden paths, and **Teleport** to jump to placed glyphs.  
- Collect **Runes** and **Mana Orbs**, avoid enemies, and reach the exit before the timer runs out.  
- Pause with **Esc** (or the pause button on mobile).
