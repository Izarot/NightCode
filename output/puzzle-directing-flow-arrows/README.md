## 🕹️ How to Play

Welcome, Director! Your job is simple: **place directional arrow tiles on the grid to guide tiny Runner creatures from Spawners into Exits** — without losing too many to Hazards.

### The Loop

1. **SETUP** — Study the grid. See the Spawners (gold 🟡), Exits (green 🟢), and Hazards (red 🔥). Pick tiles from your inventory bar at the bottom.
2. **PLACE** — Left-click any empty cell to drop your selected tile. Right-click to rotate it. Don't forget: Runners keep moving in their last direction unless an arrow redirects them!
3. **GO!** — Hit `SPACE` or the **GO** button to start the Run Phase.
4. **WATCH** — Sit back as Runners stream out and follow your carefully-laid paths.
5. **WIN** — Hit your Save / Lost / Time objectives to advance. Miss any? Tweak your layout and retry — no penalty!

### Controls Cheat Sheet

| Key | Action |
|---|---|
| `1`–`6` | Quick-select tile type |
| `R` | Rotate selected tile |
| `Delete` | Remove tile under cursor |
| `Z` | Undo last placement |
| `Space` | Start the Run Phase |
| `+` / `-` | Speed up / slow down simulation |
| `Esc` | Pause |

> 🖱️ **Mouse**: Left-click = place · Right-click = rotate · Middle-drag = pan
> 📱 **Touch**: Tap = place · Long-press = rotate / remove

### Tile Types at a Glance

| Tile | Does What |
|---|---|
| ▶ Arrow | Redirects a Runner to face that direction |
| ➡ Conveyor | Forces Runner forward — no turning back |
| ▷ One-Way | Pass-through one way only; wall from the other |
| ⧖ Mirror | Bounces incoming Runners 90° |
| ✦ Teleporter | Warps Runners to its paired teleporter |
