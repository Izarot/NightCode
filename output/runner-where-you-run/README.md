# Giant Keyboard Runner

A side‑scrolling, rhythm‑driven runner where you dash across an endless mechanical keyboard, hitting glowing keys for points and dodging quirky obstacles.

## How to Play
- **Move**: Arrow keys (or on‑screen buttons) to scroll left/right.  
- **Jump**: Spacebar (or tap) to leap onto the next key.  
- **Double Jump**: Press jump again while in the air for a second boost.  
- **Collect**: Grab power‑ups (Sustained Note, Turbo Boost, Ghost Mode, Magnet) for temporary perks.  
- **Score**: Rack up points by hitting keys in the musical sequence and chaining combos—watch the multiplier grow!  
- **Avoid**: Stay clear of moving keycaps, falling debris, and overheating keys that flash red.
