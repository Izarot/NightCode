#  🎮 Dodge Dot

**Survive the geometric onslaught!** A minimalist arcade dodge-'em-up where you're a tiny cyan dot fleeing an endless rain of shapes. How long can you last?

---

## 🕹️ How to Play

| Control | Action |
|---------|--------|
| **Arrow Keys** / **WASD** | Move your dot |
| **Touch & Drag** | Steer (mobile) |
| **Space** / **Tap** | Pause/Resume |

**Objective:** Don't touch anything. Circles, squares, triangles—they all spell doom.  
**Scoring:** +1 point per second alive. Milestone bonuses every 100 points.  
**Difficulty:** Spawns accelerate. Speeds climb. After 60s? *Chaos mode* activates.
