# Equation Shift 🧮✨

**A math-puzzle arcade game where you swap tiles to build valid equations!**

---

## 🎮 How to Play

1. **Select** a tile (click/tap or arrow keys + Enter).
2. **Swap** it with an orthogonal neighbor (up/down/left/right).
3. **Form** a valid equation — exactly one `=`, evaluated left-to-right.
   - ✅ `3 + 4 = 7`  
   - ❌ `3 = 4 + 7`
4. **Clear** — matched tiles vanish, new ones drop from the top.
5. **Win** the level by clearing the target number of equations before moves or time run out!

### Controls
| Action | Mouse/Touch | Keyboard |
|--------|-------------|----------|
| Select | Click / Tap-hold | Arrow keys + `Enter` |
| Swap | Drag to neighbor / Click neighbor | Arrow keys (while selected) |
| Undo | Button (↩) | `Z` |
| Reset | Button (↺) | `R` |
| Hint | Button (✦) | `H` |
| Pause/Menu | — | `Esc` |
