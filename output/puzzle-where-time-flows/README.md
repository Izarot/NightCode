# Chronosphere

**Genre:** 2D Puzzle / Time Management  | **Platform:** Web Browser (HTML5 Canvas)

## The Premise
Navigate a neon-noir labyrinth of interconnected rooms, each governed by its own independent temporal clock. By manipulating the flow of time within a single room, you can resolve paradoxes and solve spatial puzzles without affecting the rest of the world.

## How to Play
*   **Move:** Use `WASD` or Arrow keys. Click the mouse to direct your character via point-and-click pathfinding.
*   **Time Manipulation:** Hold down `Shift` to cycle the current room's time scale: `1x` (Normal) -> `2x` (Fast Forward) -> `0.5x` (Slow) -> `-1x` (Rewind) -> `1x`.
*   **Solve Puzzles:** Change the local time to interact with entities. Rewind time to catch falling latches before they lock doors open. Fast-forward to ride moving platforms across spike pits. Each room operates in strict isolation—solve them one at a time!

## Visual Style
A minimalist vector art aesthetic bathed in neon-noir. Time states are color-coded:
*   🔵 **Normal (Cyan):** Default ambient lighting.
*   🟣 **Fast Forward (Magenta):** Pulsing outlines, accelerated trails.
*   🟠 **Rewound (Amber):** Flickering textures, ghostly afterimages.
*   🟣 **Paused (Violet):** Static frame-by-frame rendering, heavy bloom.

## Tech Stack
Built with HTML5 Canvas, an Entity Component System (ECS) architecture, and standard `requestAnimationFrame` delta-time loops.
