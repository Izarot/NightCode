# 🎮 CASCADE

*A hypnotic number-merging puzzle where tiles cascade down, collide, and combine into bigger numbers!*

---

## How to Play

**Drop tiles from the top and watch the magic happen.**

When two tiles with the same number touch, they merge into one tile with double the value. Chain reactions = big points! The grid fills from the bottom up — game over when there's no room left at the top.

### Controls

| Action | Desktop | Touch |
|--------|---------|-------|
| Move | `←` `→` Arrow Keys | Swipe left/right |
| Soft Drop | `↓` Arrow Key | Swipe down |
| Hard Drop | `Space` | Tap |
| Pause | `P` or `Esc` | Two-finger tap |

### Scoring

- **Merge reward:** `value × 10`
- **Chain bonus:** Multiplier increases with consecutive merges in one drop

Merge two **2**s → **4** (+40 points)
Merge two **4**s → **8** (+80 points)
Chain 3 merges → up to **×3.75** bonus multiplier!
