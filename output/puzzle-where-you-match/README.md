# 🌑 Chromatic Shadows: A Puzzle Match Game

> Manipulate objects. Cast colored shadows. Solve the puzzle.

---

## 🎮 How to Play

1. **Select** an object by clicking or tapping it.
2. **Drag** it to a new position on the dark stage.
3. **Rotate** objects (45° increments) to angle their shadows just right.
4. **Scale** objects to resize their shadows and fit the target zones.
5. **Stack** objects to create composite shadow patterns.
6. **Match** every colored shadow to its glowing target zone to complete the level!

### Controls

| Input | Action |
|---|---|
| Click / Tap & Drag | Move object |
| Right-Click / Double-Tap | Rotate object |
| Scroll / Pinch | Scale object |
| Arrow Keys | Fine-tune position |
| Spacebar | Reset object position |

### Tips
- Watch for **occlusion** — objects block each other's shadows!
- Use **mirrors** and **color filters** in later levels to bend light and shift shadow hues.
- Keep an eye on your **move counter** and **timer** — some levels are tricky!
