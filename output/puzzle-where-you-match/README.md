## 🎮 How to Play

**The Goal**  
Align identical shapes along every radial spoke — from the outermost ring to the core. When a spoke fully matches, it locks into a permanent crystal. Complete all spokes to awaken the core and clear the level.

**Controls**

| Input | Action |
|-------|--------|
| **Drag a ring** | Free-spin with momentum; releases snap to nearest slot |
| **Mouse wheel** | Nudge ring ±1 slot (smooth tween) |
| **← / →** | Rotate selected ring ±1 slot |
| **Tab** | Cycle ring selection (keyboard play fully supported) |
| **U / Ctrl+Z** | Undo last move (costs 1 move) |
| **H** | Hint — shows ghost arrow on target ring (max 3/level) |
| **R** | Restart level |
| **Esc / P** | Pause |

**Touch:** Drag rings directly. Minimum hit band ensures fat-finger friendliness.
