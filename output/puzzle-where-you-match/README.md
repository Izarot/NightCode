# 🛤️ Shape Path Puzzle

Connect the dots. Literally.

Drag geometric shapes onto the grid to build a neon path. A token will zip along your creation using smooth interpolation physics—try to get it from Start to End before you run out of moves!

## How to Play
1. **Pick a shape** from the bottom dock.
2. **Drag and drop** it onto the grid. It snaps to the nearest tile.
3. **Align edges** so shapes connect into one unbroken chain.
4. **Watch the token** travel from Start to End along your path.
5. **Don't run out of moves!** Each placement costs one move.

## Controls
- **Mouse/Touch:** Drag shapes from the dock to the grid.
- **Undo:** Revert your last placement.
- **Reset:** Clear the board and try again.

## Neon Goodies
- Smooth lerp movement with ease-out cubic easing
- Flood-fill path validation
- Particle sparks on placement
- Glassmorphism HUD with monospace typography
