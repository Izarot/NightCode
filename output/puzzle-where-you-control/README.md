# 🎮 DUALITY

> *Two bodies. One input. One tether. Infinite chaos.*

A precision puzzle-platformer where you control **both** characters at once. Tied together by an elastic tether, **Prime** (gold, momentum) and **Echo** (cyan, float) must navigate asymmetric environments by mastering the art of *desyncing their positions while syncing their timing*.

Built on **HTML5 Canvas + Vanilla TypeScript**, running at a buttery 60fps with a custom ECS architecture.

## 🕹️ How to Play

### The Duo
- **Prime (Gold)** — Heavy, snappy, builds momentum. Can **Dash**.
- **Echo (Cyan)** — Light, floaty, slides on ice. Can **Double Jump**.

### Controls
| Action | Key |
|:---|:---|
| Move | `A` / `D` or `←` / `→` |
| Jump | `W` / `↑` / `Space` |
| Dash *(Prime only)* | `Space` *(mid-air)* |
| **Quantum Swap** *(hold to preview, release to execute)* | `Shift` / `E` |
| Soft Reset | `R` |
| Pause | `Esc` |

### Core Loop
1. **Tether Tension** — Stay within 6m or get yanked back.
2. **Phase Barriers** — One twin passes, the other doesn't.
3. **Pressure Plates** — Some need weight (Prime), some need lightness (Echo), some need *both at once*.
4. **Throw Mechanic** — No button. Just Dash as Prime and watch Echo *fly*.
5. **Quantum Swap** — Instantly exchange positions *and* velocities. Mind the walls.
6. **Die Together, Win Together** — One hit kills. Both respawn. One exit door requires simultaneous entry.

### Tips
- 🟡 **Let Prime slide** — releasing input keeps 95% velocity.
- 🔵 **Echo skates** — turning input reverses momentum for snappy direction swaps.
- ⚡ **Hold `Shift` to preview** your swap trajectory in slow-motion before committing.
- 💀 **You will die.** A lot. The death counter is your friend.
