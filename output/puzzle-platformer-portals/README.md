# Portal Shift

A 2D puzzle‑platformer where you place paired portals to solve spatial puzzles.

## How to Play

- **Move:** WASD or Arrow keys  
- **Jump:** Spacebar  
- **Place Portal A (Blue):** `Q`  
- **Place Portal B (Orange):** `E`  
- **Aim:** Use the mouse (or direction keys) to aim, then click to drop a portal.  
- **Goal:** Navigate each level, using portals to bypass hazards, reach collectibles, and exit the level.
