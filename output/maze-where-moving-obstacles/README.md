# 🐺 Predator's Labyrinth

**Evade. Outsmart. Survive.**

---

## How to Play

Navigate through cyber-noir labyrinths while evading crimson sentries on their relentless patrol routes.

### Controls
| Key | Action |
|-----|--------|
| `W` / `↑` | Move Up |
| `A` / `←` | Move Left |
| `S` / `↓` | Move Down |
| `D` / `→` | Move Right |
| `Shift` | Sprint (uses stamina) |
| `ESC` | Pause |

### Your Mission
- **Reach the exit** (glowing beacon) without getting caught
- **Avoid the red sight cones** of patrolling sentries
- **Manage your stamina** — sprint to escape, but don't burn out
- **Learn the patterns** — every sentry follows the same route

> *You cannot fight. You can only think faster than they patrol.*

---

### Tips
- Watch patrol patterns before making your move
- Sprint only when absolutely necessary
- Checkpoints save your progress — use them
- The red vignette warning means a sentry is close
