# PhaseShift: Veil of Shadows  
*Dodge, Phase, and Outwit the Shadows!*  

## How to Play  
- **Move:** Arrow keys or `A/D` to dash left/right (speed: 5→8 units/s).  
- **Jump:** `Space` or `↑` to leap (height: 3 units). No double-jumps!  
- **Phase:** Press `E` or right-click to enter a 3-second ghost state.  
  - Become invincible, pass through enemies, and stun them on contact.  
  - **Cooldown:** 3 seconds. Can’t phase mid-air or while colliding!  
  - Hazards (spikes, etc.) still hurt—stay alert!  

## Key Features  
- **Shadowy Foes:** Enemies patrol, chase, and attack. Phase through them to stun and damage!  
- **Visual Flair:** Pixel-art levels with parallax backgrounds. Ghostly transparency + flickering outlines during phase.  
- **HUD:** Health bar, phase meter, cooldown timer, and score counter. Clean, minimalist design.  
- **Tech Specs:** Built with HTML5 Canvas + JavaScript (no libraries). 60 FPS smooth gameplay.  

## Pro Tip  
Use phase strategically—enemies resume attacking if you un-phase mid-collision!
