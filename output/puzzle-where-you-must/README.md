# Balance-Shift

A minimalist physics-puzzle game where you balance a seesaw by placing weighted objects. Use logic, torque, and spatial reasoning to achieve perfect equilibrium.

## How to Play

1. **Inspect** the seesaw layout, fulcrum position, and available weights.  
2. **Select** a weight from the inventory (click or tap).  
3. **Place** it on a valid slot on either side of the seesaw.  
4. Watch the real-time torque simulation – the seesaw will tilt until balance is reached.  
5. Achieve equilibrium (torque difference ≤ 0.5% for 0.5s) to complete the level.  
6. Progress through 15 increasingly complex puzzles, using hints sparingly for better scores!
