**Navigate rows of obstacles, hit your targets, and reach the exit — before time runs out!**

## How to Play

1. Use **Arrow Left/Right** or **A/D** keys to slide your character horizontally across each row.
2. Pass through all **targets** (lime green orbs) in sequential order within each row.

4. Complete all rows before the timer hits zero to win!

### ⚠️ Watch Out For
- **Obstacles** (dark gray blocks, moving walls, lasers, and pulsing barriers) will end your run on contact.
- **Time** counts down from 60 seconds per row — plan your route wisely!

| Key | Action |
|-----|--------|
