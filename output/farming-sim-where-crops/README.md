# 🌱 CODEFARMER  
*Grow code. Harvest logic.*

---

## 🎮 HOW TO PLAY

Welcome to **CodeFarmer** — where your farm runs on JavaScript!

1. **Plant Code Seeds**: Select a snippet from your library and plant it on tilled soil. Each snippet is a tiny program that grows into a crop.
2. **Water & Wait**: Keep your plots moist (50% starts low!) to speed up compilation. Dry plots = withered dreams.
3. **Compile to Grow**: Hit the compile button or wait for the timer. If your code runs without errors, your crop matures!
4. **Harvest Yields**: Collect Logic Points, Cycles, and Debug Tokens from healthy crops.
5. **Upgrade & Expand**: Use your earnings to unlock new snippets, expand your farm, and upgrade tools.
6. **Debug Bugs**: Syntax errors? Infinite loops? Fix them in the editor or spend Debug Tokens to auto-repair.

---

## 🛠️ CONTROLS

- **WASD / Arrow Keys** – Move your farmer
- **E / Double-Click** – Enter Plant Mode
- **Esc** – Cancel current action
- **1–5** – Quick-select tools (Hoe, Water, Fertilizer, Scanner, Harvest)
- **Mouse** – Navigate menus, place snippets, interact with plots

---

## 🧪 SANDBOXED SNIPPETS

All code runs in a secure sandbox. Only safe JavaScript is allowed — no DOM access, no prototypes, no chaos. Just pure, growable logic.

---

## 🌙 DAY/NIGHT CYCLE

Time flows in real-time. Night boosts compile speed but dims your screen. Plan your farm around the clock!

## 🏆 WIN STATE

Unlock all biomes, master complex snippets, and craft the legendary **Golden Code** to achieve full harvest enlightenment.
