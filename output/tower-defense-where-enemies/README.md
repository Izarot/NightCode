# Parasite Protocol

**A Tower Defense Game Where Your Defenses Feed the Enemy**

> *Warning: Every tower you build makes the parasites stronger.*

---

## 🎮 How to Play

1. **Place Towers** — Click a tower type in the build menu, then click a grass tile to deploy
2. **Survive Waves** — Enemies follow the glowing path; stop them before they reach the exit
3. **Manage Risk** — When towers fall, parasites absorb their value as HP. Build wisely!
4. **Upgrade & Sell** — Click placed towers to upgrade (↑ damage) or sell (60% refund)

### Controls
| Action | Input |
|--------|-------|
| Build tower | Select from menu → click tile |
| Sell tower | Right-click tower |
| Edit map | Right-click grass tile |
| Pause/Speed | Bottom bar speed buttons |

### Tower Types
| Tower | Cost | Role |
|-------|------|------|
| 🔵 Blaster | 50g | Solid single-target damage |
| ⚡ Zapper | 100g | Chain lightning to 3 enemies |
| 🟠 Cannon | 200g | Area-of-effect blast |

---

## ⚠️ The Core Mechanic

Parasites don't just have HP — they **absorb tower value** when destroying your defenses. A fully-upgraded cannon might deal massive damage... but also grant the enemy +200 HP when it falls. Strategy matters more than firepower.
