# 🍬 Candy Cascade

*A deliciously addictive Match-3 puzzle game! Swap candies, create combos, and chase high scores in this sweet cascade adventure.*

---

## How to Play

1. **Tap** a candy to select it (it will glow!)
2. **Tap** an adjacent candy to swap them
3. Match **3 or more** candies of the same type in a row or column
4. Watch them **explode** and trigger a cascade!
5. Score big with **chain reactions** — each cascade level multiplies your points
6. You have **20 moves** — use them wisely!

### Pro Tips

- 🔥 Match 4 candies to create **striped candies** that clear entire rows or columns
- 🌈 Match 5 in an L or T shape to create a **rainbow candy** that wipes out an entire color
- ⚡ Bigger combos = bigger multipliers (up to 4×!)
