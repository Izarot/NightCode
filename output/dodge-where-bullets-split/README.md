

# 🌀 PROJECT CODENAME: FRACTURE POINT

**Genre:** Arcade Bullet-Hell / Dodge 'Em Up  
**Platform:** HTML5 Canvas (Vanilla JS / TypeScript)

Survive the fracture. Dodge the seeds. Shatter the shards. In **Fracture Point**, you aren't just dodging bullets—you're turning them into hazards.

## 🎮 How to Play

| Action | Input |
| :--- | :--- |
| **Move** | `WASD` / `Arrows` / Left Stick |
| **Focus** | Hold `Shift` / Right Stick (Slow-mo + Tighter Hitbox) |
| **Pulse** | `Space` / `A` (Clear nearby projectiles) |
| **Touch** | Left half to move, Right half to focus/pulse |

### Core Mechanics
- **Survive Indefinitely:** Your score is based on time survived, multiplied by difficulty and graze bonuses.
- **Fracture Seeds:** Primary projectiles shatter into homing **Shards** when they hit walls, expire, or are hit by your **Pulse**.
- **Graze:** Fly dangerously close to bullets to charge your Pulse meter and rack up points.
- **Pulse Defense:** Spend your meter to detonate a shockwave that fractures seeds early and clears shards.
- **Integrity:** You start with 3 lives. Losing one triggers invincibility and time-slow.
