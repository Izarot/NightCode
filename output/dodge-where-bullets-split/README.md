# FRACTURE POINT

Genre: Arcade Bullet-Hell / Dodge Em Up
Platform: HTML5 Canvas (Vanilla JS)

How to Play
- Move: WASD / Arrow Keys
- Focus: Hold Shift (slow, tighter hitbox)
- Pulse: Space (clears nearby projectiles, fractures seeds)
- Touch: Left half move, right half focus/pulse

Core Mechanics
- Survive indefinitely. Score = time survived x difficulty + graze bonuses.
- Fracture Seeds shatter into homing Shards on wall hit, expiry, or Pulse.
- Graze bullets to charge Pulse and gain points.
- Start with 3 lives. Losing one gives invincibility and slow time.
