# Yarn Maze: Unravel the Path

## How to Play
Navigate procedurally generated mazes filled with dense, shifting giant yarn balls! Use precise cutting mechanics to slice through yarn obstacles, dynamically reshaping the maze and creating safe pathways to the exit.

- **Move:** WASD / Arrow keys
- **Cut:** Hold Left Mouse Button and drag to slash through yarn
- **Goal:** Unravel enough yarn to form a continuous path from Start (Green) to Exit (Gold)

## The Vibe
Top-down puzzle-action with tight physics, fuzzy yarn visuals, and a cozy but claustrophic atmosphere. Watch out for Knot Spiders if you dare!
