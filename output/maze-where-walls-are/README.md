# TETRIS FALL

## Overview
A high-speed maze navigation game where you navigate a procedurally generated labyrinth while dodging falling tetromino walls. Watch as the environment itself collapses around you—blocks settle, creating new barriers, and the ever-rising stack line threatens to crush you.

## How to Play
1. **Spawn** in the bottom-left corner of a 20×20 grid maze.
2. **Move** your character using WASD or arrow keys (grid-based, snap-to-center).
3. **Dash** by holding **SHIFT** + direction for 0.1s to move faster (up to 0.5s, cooldown 1.5s).
4. **Survive** until the stack line reaches your position or you're crushed by a falling block.
5. **Goal**: Survive as long as possible, collecting score points for tiles traveled, time survived, and settled blocks.

## Core Mechanics
- **Falling Tetrominoes**: Standard 7-piece set (I, O, T, L, J, S, Z) fall at increasing speeds (3–3.5 cells/sec).
- **Stack Line**: A red glowing line sweeps upward; if it reaches your y-position, you lose.
- **Collision**: Dodging falling blocks is easy, but settling on you is fatal.
- **Dynamic Maze**: Pre-existing walls dissolve as blocks settle, creating evolving corridors.
