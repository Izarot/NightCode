# 🎮 LayerShift

*A dimension-bending platformer where reality has layers.*

---

## 🌌 The Concept

You're trapped between worlds. **Foreground** and **Background** overlap the same space—but they're *different*. Platforms exist in one layer but not the other. Enemies patrol one dimension, blind to the next. Your only power? **Shift between them.**

Press **Space** to flip reality. Solve puzzles. Dodge hazards. Find the path that doesn't exist in *either* layer alone.

---

## 🎮 How to Play

| Action | Key |
|--------|-----|
| Move | `A` / `D` or `←` / `→` |
| Jump | `W` / `Space` or `↑` |
| **Shift Layer** | `Space` / `Left Click` |
| Pause | `Esc` |

### Core Mechanics
- **Layer Switch** — Toggle between Foreground (cyan) and Background (magenta) with a 0.3s cooldown
- **Phasing** — Pass through objects in the *inactive* layer; collide only with the *active* one
- **Wall Slide/Jump** — Hug walls, kick off, reach new heights
- **Coyote Time & Jump Buffer** — Forgiving platforming so you feel skilled, not cheated

### Win Condition
Reach the exit. Collect fragments. Don't die. (Dying is fine. You'll do it a lot.)
