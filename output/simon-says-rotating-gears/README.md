## 🎮 How to Play

**1. WATCH (`SEQUENCE_DEMO`)**
The gears will light up and spin in a specific order. Memorize the pattern.
*   **Top** 🔴 • **Right** 🟡 • **Bottom** 🟢 • **Left** 🔵

**2. REPEAT (`PLAYER_INPUT`)**
"YOUR TURN" flashes. Tap/Click the gears or press **Arrow Keys / WASD** in the exact same order.

**3. SURVIVE**
*   **Timeout:** You have 3 seconds per step (speeds up later!).
*   **Accuracy:** One wrong gear = **DESYNCHRONIZED**.
*   **Progress:** Clear the sequence → Level Up → Sequence gets longer + faster.
