# Stack Trace

**PROJECT "STACK TRACE"** — A precision puzzle-platformer where you debug code by physically manipulating buggy blocks in a side-scrolling world.

> **Autonomously generated by NightCode** — v1.0

## 🎮 How to Play

You are **The Debugger**, a digital agent tasked with compiling a broken codebase. Navigate through procedurally generated levels filled with **Static Blocks** (compiled code), **Dynamic Blocks** (live bugs), and obstacles. Your goal is to identify, isolate, and excise errors before reaching the **Exit Port**.

### Core Mechanics

| Action | Key | Effect |
|--------|-----|--------|
| **Move** | `A/D` or Arrow Keys | Walk, run, wall-slide, dodge |
| **Dash** | `Shift` | Instant burst of speed (cooldown: 0.6s) |
| **Grapple** | `RMB` / `LMB` | Hook onto grappable objects and swing |
| **Refactor** | `LMB` | Strike a bug block to convert its type (SyntaxError → LogicError → etc.) |
| **Cast** | `Q` | Fire a type-conversion projectile at targets |
| **Breakpoint** | `E` | Place a pause point to step through physics frame-by-frame |
| **Garbage Collect** | `F` | Clear memory leaks and heal yourself (ultimate, 1.5s charge) |

### The Core Loop

```
SCAN → ISOLATE → EXCISE → COMPILE → DEPLOY
```

1. **Scan** the level for `SyntaxError`, `RuntimeException`, and other dynamic blocks.
2. **Isolate** them using dash, grapple, or refactoring tools.
3. **Excise** by casting types or breaking dependencies.
4. **Compile** — trigger the compiler to validate your fixes.
5. **Deploy** — reach the exit port to complete the level.

### Design Philosophy

- **Tactile Abstraction** — feel the weight and momentum of code physics.
- **Zero UI Clutter** — the world itself is the debugger (diegetic HUD only).
- **Deterministic Physics** — no randomness; success comes from skill and knowledge.
- **Satisfying Juice** — particle bursts, screen shake, and satisfying sound effects on every fix.

### Quick Start

1. Load the game (single `index.html` file).
2. Explore the level, avoiding `NullPointer` projectiles and `MemoryLeak` towers.
3. Use **Refactor** to change block types, **Cast** to force conversions, and **Breakpoint** to slow down complex interactions.
4. Reach the **Exit Port** to compile and complete the level.

### Technical Specs

- **Engine**: HTML5 Canvas (vanilla JS/TS)
- **Architecture**: Lightweight ECS (Entity Component System)
- **Physics**: Custom AABB + SAT solver (fixed timestep 1/120s)
- **Target Performance**: 60 FPS at 1080p, 120 FPS at 720p
- **Visual Style**: Cyber-brutalist "code surgery" aesthetic with dark terminal palette
