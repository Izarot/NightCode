# Tiny Heroes – Tactical Dungeon

A bite‑size turn‑based tactical dungeon crawler where you command three tiny heroes with a single shared command each turn.

## How to Play
1. **Start the game** – use WASD / Arrow keys or click the radial command wheel.  
2. **Choose a command** – Move, Attack, Ability, or Interact. All three heroes attempt the same action simultaneously.  
3. **Watch the heroes act** – they move one tile, strike the nearest foe, unleash their special skill, or interact with the environment.  
4. **Enemies react** – AI moves, triggers traps, and the dungeon updates.  
5. **Repeat** – each turn consumes 1 shared Action Point; manage Mana and position to out‑wit the darkness.

> **Tip:** Keep the heroes adjacent for a synergy boost (+1 Attack, +5 % crit) and use the Rogue’s Stealth for a guaranteed critical strike.
